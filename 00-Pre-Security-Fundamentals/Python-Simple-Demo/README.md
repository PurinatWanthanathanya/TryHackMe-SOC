# Lab: Python: Simple Demo

**Role:** Pre-Security Student / Security Automation Trainee

## 🎯 Objective
To establish foundational programming skills in Python by developing an interactive number-guessing game, focusing on variable management, standard input/output functions, and control flow logic.

## 🚀 Execution Steps
1. **Variable Management & I/O Functions:** 
   * Initialized specific variables to store the generated secret number and the user's ongoing input.
   * Utilized core Python functions, deploying `print()` to output instructions and feedback, and `input()` to capture data directly from the user via the terminal.
2. **Conditional Logic Implementation:** 
   * Implemented conditional statements (`if-elif-else`) to evaluate the user's input mathematically against the stored secret number.
   * Programmed logical pathways to provide dynamic feedback to the user (e.g., indicating whether the guess was "too high" or "too low").
3. **Control Flow with Loops:** 
   * Deployed a `while` loop to manage the program's execution state.
   * Configured the loop to iterate continuously, allowing the user multiple attempts. The execution flow was designed to break and terminate successfully only when the exact secret number was guessed.

## 📊 Results & Evidence
* Successfully developed, debugged, and executed a Python script that functions as a complete interactive number-guessing game, demonstrating practical knowledge of program control flow.

## 🧠 Key Takeaways
* **Automation Foundation:** Learned that Python is a critical language for cybersecurity. Mastering fundamental logic (variables, loops, and conditions) is the necessary first step toward writing automated scripts for SOC operations and log parsing.
* **Controlling Program Flow:** Recognized how `while` loops and conditional logic work synchronously to make decisions dynamically based on changing user input.
* **Input Handling:** Understood the mechanics of capturing and processing raw input data from a user—a foundational concept that translates directly to handling external data sources and API responses in larger security tools.
