# Lab: Client-Server Basics

**Role:** Pre-Security Student / IT Fundamentals Trainee

## 🎯 Objective
To understand the foundational architecture of network communications by analyzing the Client-Server model, deconstructing URLs, and utilizing browser Developer Tools to inspect HTTP protocols and traffic flow.

## 🚀 Execution Steps
1. **Client-Server Architecture Analysis:** 
   * Investigated the fundamental network communication model where the Client initiates requests for resources and the Server processes and fulfills those requests.
   * Analyzed the roles of logical addressing, utilizing IP addresses to pinpoint server locations and specific Ports to identify corresponding services running on those servers.
2. **DNS & URL Component Deconstruction:** 
   * Examined the Domain Name System (DNS) as a naming service responsible for resolving human-readable hostnames into IP addresses.
   * Deconstructed URLs to identify and categorize specific components, such as the protocol scheme and the target host.
3. **HTTP Protocol & Traffic Inspection:** 
   * Investigated the HTTP protocol, with a specific focus on the `GET` method utilized for resource retrieval.
   * Leveraged browser Developer Tools to monitor, inspect, and analyze live HTTP request and response cycles.

## 📊 Results & Evidence
* Successfully mapped the client-server interaction process, resolved hostnames via DNS concepts, and actively monitored HTTP `GET` requests using built-in developer tools.

## 🧠 Key Takeaways
* **The Foundation of Web Traffic:** Recognized that all web interactions rely on the Client-Server model; understanding this flow is a mandatory prerequisite for analyzing network traffic and detecting anomalies.
* **Addressing & Service Identification:** Learned that while an IP address routes traffic to the correct machine, the Port number is essential for directing that traffic to the correct application or service.
* **Visibility via Developer Tools:** Discovered that browser Developer Tools provide immediate, invaluable visibility into HTTP methods and web application communications, acting as a lightweight traffic analysis tool.
