# Lab: Cloud Computing Fundamentals

**Role:** Pre-Security Student / Cloud Security Trainee

## 🎯 Objective
To understand the architectural shift from traditional on-premise physical servers to modern cloud infrastructure, analyze core cloud deployment and service models, and apply foundational knowledge to manage and provision compute instances effectively.

## 🚀 Execution Steps
1. **Cloud Architecture & Benefits Analysis:** 
   * Evaluated the evolution of enterprise infrastructure, transitioning from physical hardware to scalable cloud environments.
   * Analyzed fundamental cloud computing characteristics, emphasizing dynamic scalability, on-demand self-service provisioning, and the operational efficiency of pay-as-you-go pricing models.
2. **Service & Deployment Model Categorization:** 
   * Differentiated between primary cloud deployment strategies: **Public Cloud**, **Private Cloud**, and **Hybrid Cloud** environments.
   * Investigated the shared responsibility and operational scope across different service models: **IaaS** (Infrastructure as a Service), **PaaS** (Platform as a Service), and **SaaS** (Software as a Service).
3. **Practical Cloud Instance Management (AWS):** 
   * Engaged in practical exercises utilizing **AWS EC2 (Elastic Compute Cloud)** to simulate real-world cloud administration.
   * Managed virtual instance configurations and analyzed environment costs to understand the economic impact of hardware provisioning in the cloud.

## 📊 Results & Evidence
* Successfully categorized cloud service models, analyzed deployment strategies, and provisioned/managed virtual instances within an AWS EC2 environment while monitoring configuration costs.

## 🧠 Key Takeaways
* **The Paradigm Shift:** Learned that cloud computing is not just about using someone else's computer; it is about transforming rigid capital expenditures (buying servers) into flexible operational expenditures (pay-as-you-go) with infinite scalability.
* **Understanding "As-a-Service":** Recognized that security and management responsibilities shift depending on the model. In **IaaS**, the user manages the OS and applications, whereas in **SaaS**, the provider handles everything under the hood.
* **Hands-on Cloud Operations:** Discovered that deploying resources in the cloud (like AWS EC2) is incredibly fast but requires careful cost analysis and configuration management to avoid unnecessary billing and maintain a secure baseline.
