# Lab: JavaScript: Simple Demo

**Role:** Pre-Security Student / Web Security Trainee

## 🎯 Objective
To establish foundational JavaScript programming skills by developing an interactive number-guessing game, focusing on variable declaration, data type conversion, control flow logic, and execution within a Node.js or browser environment.

## 🚀 Execution Steps
1. **Variable Declaration & Environment Setup:** 
   * Configured the execution environment utilizing either Node.js or browser-based Developer Tools.
   * Declared necessary program variables utilizing modern JavaScript syntax, explicitly choosing between `let` (for mutable variables) and `const` (for immutable constants).
2. **Data Conversion & Conditional Logic:** 
   * Implemented data sanitization by utilizing the `parseInt()` function to accurately convert string-based user inputs into integers for mathematical comparison.
   * Programmed logical pathways using `if-else` conditional statements to evaluate the user's guess against the target secret number and trigger appropriate feedback.
3. **Control Flow & Standard Output:** 
   * Managed the continuous execution state of the program by deploying a `while` loop.
   * Utilized the strict inequality operator (`!==`) to ensure the loop continued until the exact correct number was guessed.
   * Deployed `console.log()` methods to output real-time instructions and feedback directly to the terminal or browser console.

## 📊 Results & Evidence
* Successfully developed, debugged, and executed a JavaScript program that functions as an interactive number-guessing game, demonstrating practical knowledge of JS control flow and data type handling.

## 🧠 Key Takeaways
* **Web Security Foundation:** Learned that JavaScript is the backbone of the modern web. Understanding its core logic and syntax is a mandatory prerequisite for analyzing malicious web scripts and understanding Web Application Security.
* **The Importance of Data Types:** Recognized the critical necessity of type conversion (e.g., using `parseInt()`). Comparing a string input directly to an integer without conversion often leads to logical errors and application crashes.
* **Modern JS Standards:** Understood best practices in variable declaration by utilizing `let` and `const` to prevent scope-related bugs, ensuring cleaner and more secure code execution.
