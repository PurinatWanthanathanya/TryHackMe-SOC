# Lab: Extending Your Network

**Role:** Pre-Security Student / Network Infrastructure Trainee

## 🎯 Objective
To understand core networking components and security infrastructure required to extend network connectivity, including Port Forwarding, Firewalls, Routers, VLAN segmentation, and Virtual Private Networks (VPNs).

## 🚀 Execution Steps
1. **Connectivity & Port Forwarding Configuration:** 
   * Analyzed how **Port Forwarding** functions to map external requests to internal services, enabling controlled external access behind a Network Address Translation (NAT) barrier.
2. **Firewall & Hardware Routing Infrastructure:** 
   * Evaluated **Firewall** operations functioning primarily at Layers 4 and 5, utilizing stateful and stateless inspection methods to permit or deny traffic based on established security rules.
   * Investigated networking hardware roles, specifically examining how **Routers** manage traffic routing across disparate networks and how **Switches** utilize **VLANs (Virtual Local Area Networks)** to segment traffic logically for enhanced security.
3. **Secure Tunneling & VPN Evaluation:** 
   * Examined Virtual Private Network (VPN) technologies designed to secure communications across public networks.
   * Contrasted authentication-focused protocols like **PPP (Point-to-Point Protocol)** with the more robust, IP-framework-based **IPSec** security architecture.

## 📊 Results & Evidence
* Successfully evaluated network extension methodologies, mapped firewall traffic inspection rules, and analyzed VLAN segmentation and secure VPN tunneling frameworks.

## 🧠 Key Takeaways
* **Bridging the Gap:** Learned that extending a network requires balancing accessibility and security; features like Port Forwarding make internal resources available, but require strict monitoring to prevent unauthorized entry.
* **Segmentation is Security:** Recognized that switches using **VLANs** are vital for network hygiene, preventing lateral movement by logically separating sensitive endpoints from standard user traffic.
* **VPNs Protect Data in Transit:** Understood that protocols like **IPSec** provide a secure, encrypted framework across public infrastructures, essential for modern remote work and enterprise security.
