# Lab: Linux CLI Basics

**Role:** Pre-Security Student / IT Fundamentals Trainee

## 🎯 Objective
To master fundamental Linux Command Line Interface (CLI) operations, including file system navigation, data retrieval, and system enumeration, establishing a strong foundation for advanced cybersecurity and server administration tasks.

## 🚀 Execution Steps
1. **Directory Navigation & File Management:** 
   * Navigated the Linux hierarchical file system using core commands such as `pwd` (print working directory) to identify the current location.
   * Utilized `ls` to list directory contents and `cd` (change directory) to traverse through multiple file paths efficiently without a Graphical User Interface (GUI).
2. **Data Inspection & File Searching:** 
   * Executed the `find` command to locate specific files across the entire file system based on naming conventions.
   * Utilized the `cat` (concatenate) command to output and read the raw contents of files directly within the terminal interface, completing assigned data extraction tasks.
3. **System Profiling & Enumeration:** 
   * Conducted initial system enumeration using `whoami` to verify the current user's privilege level.
   * Executed `uname -a` to extract detailed kernel and operating system architecture information.
   * Monitored system storage resources and disk partitions using the `df -h` (disk free, human-readable) command.

## 📊 Results & Evidence
* Successfully navigated the Linux terminal, located specific hidden files using CLI utilities, and extracted vital system and hardware information.

## 🧠 Key Takeaways
* **CLI over GUI:** Learned that in enterprise and cybersecurity environments, servers rarely have Graphical User Interfaces. Mastery of the CLI is mandatory for efficient system administration and incident response.
* **Enumeration is the First Step:** Recognized that commands like `whoami` and `uname -a` are foundational not just for IT support, but for security analysts and ethical hackers mapping out a system's layout and potential vulnerabilities.
* **Command Line Efficiency:** Discovered that utilizing commands like `find` drastically reduces the time required to locate critical data or hidden files compared to manual folder traversal.
