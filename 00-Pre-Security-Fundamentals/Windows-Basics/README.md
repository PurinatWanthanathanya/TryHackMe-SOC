# Lab: Windows Basics

**Role:** Pre-Security Student / Windows System Administration Trainee

## 🎯 Objective
To understand core Windows administration, account management privilege models, system monitoring utilities, and foundational built-in security features within the Windows operating system environment.

## 🚀 Execution Steps
1. **User Account Administration & Privilege Models:** 
   * Analyzed Windows user access tiers, categorizing accounts into **Guest**, **Standard User**, and **Administrator** levels.
   * Examined privilege escalation boundaries, identifying how Administrator permissions grant full control over system configurations and security policies.
2. **System Navigation & Process Monitoring:** 
   * Navigated the Windows hierarchical file system utilizing **File Explorer** to locate critical system directories and files.
   * Leveraged **Task Manager** to inspect running background processes, track resource consumption (CPU, RAM, Disk), and identify abnormal process behaviors.
3. **Security Configurations & Management Consoles:** 
   * Configured native defense mechanisms using **Windows Security**, focusing on Virus & Threat Protection and Defender Firewall rules.
   * Contrasted system configuration management between modern **Windows Settings** and the legacy **Control Panel** applets.
   * Utilized native diagnostic commands (such as `systeminfo` and `ipconfig`) to extract host configuration baselines and network adapter statuses.

## 📊 Results & Evidence
* Successfully navigated core Windows administrative interfaces, classified user privileges, monitored active processes using Task Manager, and verified Windows Defender security settings.

## 🧠 Key Takeaways
* **Principle of Least Privilege:** Learned that running daily tasks under standard user accounts reduces the attack surface, preventing unauthorized software execution without explicit administrator elevation.
* **Process Visibility via Task Manager:** Recognized Task Manager as the primary native triage tool to quickly spot rogue, high-resource, or disguised processes during initial security inspections.
* **Modern vs. Legacy Administration:** Understood that comprehensive Windows administration requires familiarity with both modern Windows Settings and classic Control Panel consoles to access all configuration layers.
