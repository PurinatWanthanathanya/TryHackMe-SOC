# Lab: Systems as Attack Vectors

**Role:** Junior Security Analyst / SOC Analyst Trainee

## 🎯 Objective
To analyze how underlying systems and IT infrastructure serve as attack vectors, differentiate between software vulnerabilities (CVEs) and system misconfigurations, and apply defensive strategies such as patch management and configuration auditing to harden enterprise attack surfaces.

## 🚀 Execution Steps
1. **Attack Surface & Threat Vector Classification:** 
   * Classified enterprise system vectors into three core risk categories: **Human-Led Actions** (weak password practices, unauthorized device usage), **Software Vulnerabilities** (unpatched flaws, Zero-days), and **System Misconfigurations** (exposed services, default credentials, improper firewall rules).
2. **Vulnerability Assessment & CVE Tracking:** 
   * Investigated common software vulnerabilities by tracking Common Vulnerabilities and Exposures (CVEs) across operating systems and enterprise applications.
   * Examined the lifecycle of Zero-day vulnerabilities and the critical role of timely patch management schedules to remediate software-based flaws.
3. **Configuration Auditing & System Hardening:** 
   * Audited system configurations to identify insecure default settings and misconfigured network defenses that cannot be fixed by standard software patches.
   * Applied hardening best practices, including rigorous configuration audits, strict access controls, and robust network/endpoint protection policies to close exposed attack vectors.

## 📊 Results & Evidence
* Successfully mapped system-level attack vectors, differentiated vulnerability mitigation techniques from configuration hardening, and outlined an audit strategy to secure exposed IT infrastructure.

## 🧠 Key Takeaways
* **Vulnerabilities vs. Misconfigurations:** Learned a vital distinction for defense—while **Software Vulnerabilities** require vendor patches and updates to fix, **System Misconfigurations** (e.g., weak access policies or exposed administrative ports) require thorough configuration audits and hardening guidelines.
* **Patching is Not a Silver Bullet:** Recognized that even a fully patched system remains highly vulnerable if standard security configurations (such as default passwords or overly permissive firewall rules) are neglected.
* **Holistic System Protection:** Understood that securing a system requires a multi-layered approach combining automated Patch Management, regular Configuration Audits, and robust Endpoint/Network protections to effectively reduce the attack surface.
